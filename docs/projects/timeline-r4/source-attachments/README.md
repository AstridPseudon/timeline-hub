# Supplemental source attachments

These files preserve source outside the four current product candidate refs. `source-attachments.json` maps exact sizes and SHA-256 values, original paths or archive members where known, and qualification limits. `SUPPLEMENTAL-SOURCE-PRESERVATION.md` summarizes each group.

`HISTORICAL-TIP-COVERAGE.json` maps the bounded inventory of 897 task-owned branch/worktree aliases to verified current public refs, exact-live upstream refs, or exact historical preservation refs. `HISTORICAL-PUBLICATION-PROGRESS.json` records non-force publication and fresh remote verification for SDK, Runtime, and App archive refs. Composition source refs and its separate publication ruling are in `../source-refs.json` and `../assets/composition-publication-ruling-262.md`.

The J029 files are a historical ZIP snapshot only. The primary App audio-resume patch and unbound App-hydrator blobs are unqualified historical/WIP variants; none is applied to the current candidate.
