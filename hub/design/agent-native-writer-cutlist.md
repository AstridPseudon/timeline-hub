## Current replacement boundary

The current native path is `TimelineSession` (`astrid/sdk/timeline/sync.py`) → registered `EditCommand` capture/execute → Runtime commit. `Checkout.attach()` and `NativeSheet` are bounded adapters over that path. Current qualified ordinary families are clip move/trim/set/params, parent track label, occurrence media/placement/delete/duplicate/pool/unplace, and video unplace. CLI `edit` ordinary trim and `apply --native` use it. `NativeSheet` is not a whole-document writer.

The old path is still live for detached checkout publication, narration, script publication, element update, parent-media replacement, and producer/approval publication. “Held” means the old positive behavior remains; it is not permission to turn it into a refusal.

## Unsupported families that remain live

The current native surface does not cover arbitrary sheet DSL, sequence/structure/chapter restructure, narration/text binding, sound/music authoring, cut notes, formulas, selected-pack opaque parameters, or whole-document replacement. The corresponding legacy writers stay live or held. A missing native primitive is a refusal boundary, not a deletion and not a reason to weaken a passing positive test.

The current timing compiler is explicitly opt-in (`astrid/sdk/timeline/compiler.py:29`). Native commit responses carry compiler identity, but the compiler is not yet proven as the default/only derived-timing writer for every detached Checkout, script, narration, and legacy publication path. Treat default activation as a separate gate: route every supported commit through the compiler, prove rational FPS/half-open/anchor behavior and readback, then remove old timing writers. This is separate from read-only marker/signal interfaces. Marker resolution currently fails closed when a captured resolver is absent (`_timing_evaluators.py:233`); signals/markers are read-only seams/fixtures before the hard stop, not new authoring features and not reasons to cut these writers.

## Exit criteria

The cutlist is closed only when the current source has no production caller of WC1–WC8 publication/merge helpers, WC10’s route has no Agent caller, and `rg` confirms only read-side compilation/feedback plus explicitly retained unsupported adapters. Every removed positive has a named command/proposal replacement with real Agent/Runtime tests for exact authored state, retry/restart, rebase/conflict, inverse/ABA, opaque fields, and no renderer dependency.
