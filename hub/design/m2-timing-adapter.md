The single-source fixture has occurrence `occ`/shot `shot` starting at 2000 ms;
raw clip `voice` starts at local 1 s, uses media-source window `[2,6)` and speed
2. Its derived interval is `[3,5)` seconds. The second “again” starts at media
second 3, hence timeline second 3.5 before the declaration's `+1f` and main
Moment frame-floor policy. At exact canvas fps `30000/1001`, the card derives
`[7007/2000, 8007/2000)` seconds and frame interval `[105,120)`.

**Known rate-parity boundary:** the initial public legacy publication invokes
`visual_seam.normalize_closure`, which rejects an object-valued `output.fps`
with `ValidationError: visual timing fps must be finite and positive`.
The fixture therefore uses numeric `output.fps = 30000 / 1001` there, while
persisting exact rational canvas fps `{numerator:30000, denominator:1001}`.
The pure compiler reads the exact canvas rational. This proves its arithmetic,
not rational-rate parity across all old writers/readers. No Runtime code was changed.

## Executable retained-source proof

[`test_timing_retained_inputs.py`](/home/user/work/wt/agt-m2-timing-source-adapter/tests/editing_conformance/test_timing_retained_inputs.py)
contains six cases:

1. Build an untracked initial film through public Runtime APIs. A startup test
   provider retains the real transcript V1 through `port.transcript_source`
   and `port.accept`, using the existing `DocumentPin` dependency/manifest
   envelopes. This mirrors Runtime's retained-input fixture; it is explicitly
   **not** a first-source-authoring Agent command. Runtime generates the actual
   receipts, retained rows and publication history; there are no SQL writes or
   fabricated receipts.
2. Reopen with the actual Agent provider; execute real `track.create`, and
   observe its genuine `_hydrate` result. First selection derives the binding
   from this authorized bundle and document, never from a caller-provided
   source or binding. Compile the interval above.
3. Public CAS overwrites the producer Document to V2 with changed word times
   and generated word IDs. Close Runtime. A **fresh Python interpreter** opens
   the realm, runs the actual Agent's dry-run command, hydrates V1 and performs
   first selection/compilation. Its full captured V1 header/content and exact
   timing match. No in-memory binding is passed into the new process.
4. Reopen again and perform a real Agent command. It still hydrates V1 while
   public `get_document` reports V2. Corrupt the detached target's `at` to 99;
   compiling with the original consumed binding still derives `[105,120)` and
   preserves the authored cache value 99 in the returned bundle. The original
   `TimingInputs` remains unchanged. This detached probe is not claimed as an
   accepted save/default compiler behavior.
5. Source-read authority revoked **after opening the closure**, an unavailable
   exact version, and an actually existing foreign-project transcript all
   refuse through the real port without changing the head. Missing captures
   and foreign scoped captures also fail atomically in the pure compiler.

## Stable choice through acceptance and rebase: the missing seam

The real provider currently supports `clip.move`, `track.create`, inverse and
restore, not a declaration-authoring command:
[`operations` / `validate_command`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/commands.py:34).
M1 move deliberately clears the moved clip's old relations without evaluating
word text. That settled scope is preserved.

The existing recorder already persists exact transcript dependencies via
[`compile_inputs`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/_recording.py:101).
It does **not** record word selection for unchanged anchors. The executable
stale track-create test accepts a real intervening source move, rebases,
reopens, and reads accepted history: the declaration and exact V1 dependency
survive, but `bindings` is empty. Feeding just that captured bundle/document to
the pure compiler correctly refuses `missing exact word binding`. Injecting
a caller binding is refused by the actual provider as `capture_mismatch`.

The stronger counterexample is
[`test_reselecting_ordinal_after_real_rebase_silently_changes_raw_source_clip`](/home/user/work/wt/agt-m2-timing-source-adapter/tests/editing_conformance/test_timing_retained_inputs.py:308):

- Two actual raw clips `voice` and `other` use the same CAS media and pinned
  transcript in the same occurrence. Initially `#2` selects the second word
  from `voice`.
- A real accepted `clip.move` places `voice` after `other`. A parent track-create
  authored at the previous base successfully rebases over it.
- Looking up `#2` again now selects `other`. Declaration, document ID, version,
  digest and **word ID** are identical; source raw clip differs. Compiling the
  original consumed binding follows `voice`; compiling the reselected binding
  puts the target entirely earlier. Accepted history still has only the
  transcript dependency and no word binding, including after reopening.

This is why an adapter cannot repair the gap by searching the current head.
The positive fresh-process case above is a new first selection over unchanged
source layout, **not** proof of persisted word-choice restoration.

Existing `AgentBinding` (`key/ref/policy/dependencies`), exact transcript
`AgentDependency`, authored reads/selections and accepted commands are the
right storage/ABI carriers. No additional field has been shown necessary.
Agent still needs the concrete declaration handler's authoritative selection
and replay semantics: capture target/field/declaration, the source occurrence
and raw clip, every selected word, and its exact pin/map dependencies; then
replay the original choice or conflict instead of silently selecting again.
[`Recording.finish`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/_recording.py:125)
currently projects only clip/track/occurrence bindings into command claims,
while `AnchorIdentity` retains legacy `word:<segment>:<index>` spelling.
Main generated `word:<digest>` IDs cannot simply be inserted into that legacy
command field. A legacy ordinal can only be resolved against its authenticated
immutable document and bound raw clip, never treated as a stable ID by itself.
This report does not invent a serialized binding/key convention. Implement
that Agent semantic seam in the registry port and validate it with the
existing recorder/schema machinery before a general adapter is justified.

## Remaining integration and deletion paths

- Add authoritative word/declaration capture to the actual registered command
  and recorder; support accepted-history extraction, original-choice replay,
  inverse/restore and restart tests. Existing
  [`rebase.replay`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/rebase.py:8)
  executes original commands, so binding retention and claim validation must
  survive that execution, rather than being discarded and reselected.
- A later small pure adapter can translate those verified existing records
  plus `_hydrate`'s already captured inputs into `TimingInputs`. It must do no
  port/source IO and refuse missing, ambiguous, stale or foreign bindings.
- Review how derived intervals are applied/recorded before
  [`document_from_bundle`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/commit.py:161)
  invokes main's graph publication converter. That converter is still not the
  word timing compiler. Do not enable this kernel as the default provider
  compiler until complete consumer parity and removal strategy are reviewed.
- Preserve explicit refusal for nonidentity placement maps, clip millisecond
  codecs, explicit time maps, shared-shot materialization gaps, sequence fits,
  formulas, orphan caches, until-film-end bases, beats/markers and reflow.
- Migrate/parity-test and then delete duplicate derived writers in
  [`reflow.py`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/reflow.py:149)
  (`reflow`, `retime`, `_place_on`, `resolve`),
  [`model.py`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline/model.py:259)
  timing setters, narration/music/sequence paths and deprecated
  [`timeline_editing.py`](/home/user/work/wt/agt-m2-timing-source-adapter/astrid/sdk/timeline_editing.py:359)
  helpers/consumers. No deletion or whole-compiler parity is claimed here.
